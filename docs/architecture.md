Я сделал программу на Python с использованием Kafka и Faust.
Программа получает сообщения от пользователей, проверяет блокировки и запрещённые слова.
Если пользователь заблокирован, сообщение не проходит. Если в тексте есть запрещённое слово, оно заменяется звёздочками.
После проверки сообщение отправляется в другой Kafka-топик.
## Как работает программа
1. Сообщение приходит в топик `messages`.
2. Faust получает сообщение.
3. Проверяет, не заблокирован ли отправитель.
4. Если заблокирован, сообщение пропускается.
5. Если не заблокирован, проверяется текст.
6. Запрещённые слова заменяются на `****`.
7. Готовое сообщение отправляется в `filtered_messages`.
Также можно добавлять и удалять запрещённые слова, блокировать и разблокировать пользователей.
## Файлы программы
В папке `app` находятся основные файлы:
```text
app/
├── __init__.py
├── censor.py
├── config.py
├── logger.py
├── main.py
└── models.py
```
**main.py** -- Главный файл программы. Здесь создаётся Faust-приложение, подключаются Kafka-топики и обрабатываются сообщения.
**config.py** -- Здесь находятся настройки Kafka, название приложения, количество партиций и другие параметры.
**models.py** -- Здесь описано, какие данные приходят в сообщениях.
Используются три модели:
- `Message` — обычное сообщение.
- `BlockUserEvent` — блокировка или разблокировка.
- `BannedWordEvent` — добавление или удаление запрещённого слова.
**censor.py** -- Здесь находится функция `censor_text()`, которая ищет запрещённые слова и заменяет их звёздочками.
**logger.py** -- Нужен для записи логов, чтобы было видно, что делает программа.

В программе используются четыре топика:

| Топик | Для чего нужен |
|---|---|
| `messages` | Сюда приходят сообщения |
| `filtered_messages` | Сюда отправляются проверенные сообщения |
| `blocked_users` | Блокировка и разблокировка |
| `banned_words` | Добавление и удаление запрещённых слов |

## Обработка сообщений
Для обработки используются три Faust Agent.
**process_blocked_users** -- Получает информацию о блокировках из `blocked_users`.
Например, пользователь `user_2` заблокировал `user_1`.
В таблицу записывается:
```text
user_2:user_1 = True
```
Это значит, что `user_1` не может отправлять сообщения пользователю `user_2`.
Если его разблокировать:
```text
user_2:user_1 = False
```
Теперь сообщения снова проходят.
**process_banned_words** -- Получает данные из `banned_words`.
Например, добавили слово `spam`:
```text
spam = True
```
Теперь программа будет заменять это слово звёздочками.
Если слово удалить:
```text
spam = False
```
Оно больше не будет заменяться.
**process_messages** -- Это основной обработчик.
Он получает сообщение, проверяет блокировку и запрещённые слова.
Если всё нормально, отправляет результат в `filtered_messages`.
## Пример сообщения
В Kafka приходит:
```json
{
  "sender_id": "user_1",
  "recipient_id": "user_2",
  "text": "Hello world"
}
```
Здесь:
- `sender_id` — кто отправил.
- `recipient_id` — кому отправил.
- `text` — текст сообщения.
## Как работает цензура
Например, в запрещённых словах есть `spam`.
Приходит сообщение:
```text
This is spam message
```
Программа заменяет слово:
```text
This is **** message
```
Регистр букв не имеет значения. `spam`, `Spam` и `SPAM` будут заменены.
## Где хранятся блокировки и слова
Для этого используются Faust Tables:

```text
blocked_users_table
banned_words_table
```
Данные хранятся через RocksDB.
Также Faust использует Kafka changelog-топики, чтобы можно было восстановить состояние после перезапуска.

- Когда добавили или удалили запрещённое слово.

- Когда сообщение успешно обработано.
